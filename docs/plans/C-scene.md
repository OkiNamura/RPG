# Очередь C: сцена и повествование

## C1. Scene budget

В `SceneState` добавить:

```ts
question?: string;    // что решается в сцене
exitCost?: number;    // сколько ходов/битов до выхода
stakes?: string;      // что потеряем, если не выйти
closedTurn?: number;
closeReason?: string;
```

- Новая сцена:
  - question = goal или «Что изменится в этой сцене?»;
  - exitCost = 4;
  - stakes = последняя ставка/угроза.
- Закрытие:
  - смена места;
  - `stalls >= 3`;
  - явный `closeReason`.
- Закрытая сцена не удаляется: `closedTurn` + `closeReason` остаются в state.
- Следующий ход после закрытия начинает новую сцену в том же месте,
  с новым id и question. Никаких таймеров по часам.
- В контекст и панель: question, exitCost, stakes, closed.

## C2. Director по событию

- Вызов Director, если:
  - сцены ещё нет;
  - сменилось место/сцена;
  - `stalls >= 2`;
  - прошло 3+ хода с прошлого вызова (страховка от голода).
- `session.lastDirectorTurn` — не в снимок, только runtime.
- Если Director выключен — `directorNote` как раньше.
- Не вызывать Director на каждом ходе.

## C3. Свайпы

- Уже есть варианты ответа/перегенерация.
- Не добавлять новый UI в этой итерации: сначала стабилизировать сцену.
- Записать в CONTEXT, что свайпы = варианты, без отдельного экрана.

## Проверки

- 3 топтания закрывают сцену, 4-й ход начинает новую;
- смена места закрывает;
- закрытая сцена сохраняет question/closeReason;
- Director не вызывается каждый ход;
- Director вызывается при stalls >= 2;
- tsc, world-test, UI 42/42.
