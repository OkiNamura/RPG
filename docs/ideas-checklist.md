# Чеклист фишек: что взято с сайтов и что уже в Omika

Собрано по aidungeon.com, mythx.ai, novelai.net, chub.ai и списку заказчика.
Статусы: **[есть]** — внедрено, **[план]** — обсудить/сделать, **[нет]** — осознанно не берём.

## AI Dungeon

| # | Идея | Статус |
|---|---|---|
| 1 | Story cards / триггеры по ключевым словам | **[есть]** лор-книга: записи с ключами, подмешиваются только при совпадении |
| 2 | Memory — закреплённые факты, идущие в каждый промт | **[есть]** блок «Память истории» в панели, `POST /memory` |
| 3 | Retry / undo / alternates | **[есть]** кнопки ⟳ править, варианты ‹ 1/2 ›, снимки по ходам |
| 4 | Авторская заметка (Author's Note) | **[план]** можно добавить отдельным полем тона на ход |
| 5 | Сценарии сообщества (каталог) | **[нет]** каталог пресетов убран по требованию |
| 6 | «Do / Say / Story» режимы ввода | **[есть частично]** быстрые действия «Осмотреться / Идти / Слушать / Говорить» |
| 7 | Скрипты и автотриггеры | **[план]** крючки есть, автосрабатываний по условию нет |

## Что можно взять дальше (по возрастанию цены)

1. Автотриггеры крючков: «когда игрок входит в место X — напомнить про Y».
2. PNG-карточки с метаданными (tEXt), совместимость с SillyTavern.
3. Арка героя по этапам (MythX) — 3–5 ступеней с испытаниями.
4. Author's Note на ход: короткая стилевая инструкция игрока.
5. Озвучка сцены (TTS) для ключевых моментов.
6. Каталог карточек с поиском по ролям и скиллам.
