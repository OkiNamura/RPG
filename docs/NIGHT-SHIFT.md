# I. Картинки

## I0. Диагноз

Сейчас:

- `scenePrompt` собирается из последних 900 знаков прозы;
- `sceneReferences` берёт до 3 референсов без имён;
- мастер-лист героя создаётся лениво;
- нет seed;
- нет проверки, что получилось;
- negative prompt общий, не сценический;
- `references: auto` можно отключить.

Отсюда:

- новый герой на каждом кадре;
- лишние персонажи;
- не та сцена;
- дрейф одежды/лица;
- текст и артефакты.

## I1. Визуальная библия персонажа

Для героя, пати и важных NPC:

```text
visualId
refs.main
refs.face
canonicalPrompt
outfit
palette
body
age
hair
eyes
marks
```

Правила:

- мастер-лист создаётся один раз;
- все сцены используют его;
- лицо и одежда не переизобретаются;
- смена одежды — отдельное состояние;
- референс нельзя потерять при перезапуске.

**Проверка:** 10 сцен подряд — одно лицо, одна причёска, один набор примет.

## I2. Контракт сцены

Вместо «последние 900 знаков» — структура:

```text
location
time
weather
present[]
  name
  ref
  outfit
  pose
  action
action
mood
camera
forbidden[]
```

Только те, кто реально в сцене. Прошлые/отсутствующие/упомянутые — не рисуются.

**Проверка:** в сцене с Асей нет Марка, если Марка нет в `present`.

## I3. Компилятор промта

Порядок:

1. стиль;
2. локация;
3. персонажи с refs;
4. действие;
5. камера/свет;
6. negative;
7. запрет лишних людей и текста.

Требования:

- одинаковый порядок;
- фиксированный seed;
- явно «same face as reference»;
- одежда из состояния;
- без абстрактной прозы.

## I4. Референсы и консистентность

- именованные референсы, а не безликий массив;
- до 9 изображений;
- сила референса;
- предыдущий кадр — только как style/identity ref, не как композиция;
- Qwen-Image-Edit / ControlNet Union — если нужен pose/depth;
- проверить, что нативный endpoint реально держит лицо.

## I5. Vision QA

После генерации:

- VLM описывает кадр;
- сравнить с контрактом сцены;
- проверить: место, время, персонажи, одежда, действие;
- face-similarity к мастер-листу;
- детект текста/лишних людей;
- score;
- при провале — один retry с исправленным промтом;
- хранить отклонённые варианты.

## I6. UI картинок

- инспектор: промт, refs, seed, контракт, QA;
- regenerate / reject;
- «закрепить внешность»;
- очередь и стоимость;
- не запускать QA/retry бесконечно.

## I7. Тесты

- 10 сцен с одним героем;
- 5 сцен с двумя персонажами;
- сцена без персонажей;
- сцена с отсутствующим персонажем — он не появляется;
- текст/панели не появляются;
- замерить latency и стоимость.

# N1–N3. Время

## N1. TimeSkip и очередь событий

- `TimeSkip`: цель, режим, статус.
- `events`: встреча, дедлайн, будильник, прибытие, поломка, триггер.
- `wakeConditions`.
- `summary` / `silent`.
- `scene` только по проверке выбора.

**Проверка:** 4 дня полёта — монтаж; прямой вопрос — сцена; поломка с выбором — сцена.

## N2. Прерывание, resume, чекпоинты

- interrupt;
- resume до цели;
- остановиться;
- изменить цель;
- снимок до/в точке/после.

**Проверка:** сон прерван — можно продолжить; дорога прервана — можно продолжить.

## N3. UI времени

- «До ближайшего события» работает через очередь;
- «Ровно N» ставит точно;
- «До утра» — 07:00;
- «Пока не разбудят» — условие;
- отмена не создаёт ход;
- нет повторного вопроса.
