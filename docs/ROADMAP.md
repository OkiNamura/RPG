# Roadmap — 2 часа в день

Реалистично: 2 часа вечером + тесты с телефона в промежутках.
Один этап — примерно одна неделя. Не растягиваем: лучше меньше, но работает.

## M0. Скелет (готово)

- [x] состояние кампании (JSON-схема)
- [x] сборка контекста по слоям + хеши сегментов
- [x] конспект append-only
- [x] разбор и применение изменений
- [x] детерминированный критик
- [x] цикл хода на моке + расчёт стоимости
- [x] сохранение/загрузка кампании (JSON)
- [x] живой CLI-цикл с командами
- [x] прогон `node src/demo.ts` и `node src/play.ts`

Проверяем: цикл крутится, стейт меняется, кэш-сегменты стабильны,
кампания переживает перезапуск.

## M1. Реальная модель (неделя 1)

- [ ] клиент OpenRouter (один файл, без SDK)
- [ ] `.env` с ключом, ключ не попадает в код и в git
- [ ] реальный ответ ведущей, стрим не нужен — сначала цельный
- [ ] прогон 20 ходов на одном мире
- [ ] замер: токены, цена хода, попадание в кэш
- [ ] сравнение 2–3 моделей по цене/качеству на одном и том же куске

Выход: понятно, сколько стоит ход и какая модель тянет стиль.

## M2. Старт игры по тегам (неделя 2)

- [ ] схема тегов (мир / тон / герой)
- [ ] генератор мира → world.md (по `Промт миры v6`)
- [ ] генератор тона → tone.md (по `Тон v1`)
- [ ] проверка согласованности: мир не противоречит тону
- [ ] «библия кампании» сохраняется и замораживается

Выход: новая кампания создаётся из тегов за один вызов, без ручной сборки.

## M3. Извлечение изменений моделью (неделя 3)

- [ ] модель отдаёт прозу и JSON раздельно (structured output или разделитель)
- [ ] суммаризатор: дельта за окно → строка в открытую арку
- [ ] модель-критик: сверка сущностей и цифр
- [ ] отбраковка и один ретрай

Выход: стейт не едет на длинных дистанциях.

## M4. Память на дистанции (неделя 4)

- [ ] триггеры конспекта: смерть, смена локации, конец арки, «СРЕЗ»
- [ ] леджер сущностей (NPC, обещания, долги) + поиск
- [ ] снапшоты и откат на ход назад
- [ ] прогон 100+ ходов, замер деградации

Выход: 100 ходов без потери деталей.

## M5. Интерфейс (неделя 5)

- [ ] минимальный веб-клиент: поле ввода, стрим, панель стейта
- [ ] телефон: адаптив, сохранение позиции
- [ ] список кампаний, продолжение

## M6. Картинки (неделя 6)

- [ ] генератор промта сцены из стейта
- [ ] дескрипторы внешности + референсы
- [ ] локальная модель на 8 ГБ (Flux-schnell / SDXL+LoRA) как черновик
- [ ] асинхронная очередь, плейсхолдер в тексте

## Что НЕ делаем сейчас

- мультиплеер, аккаунты, биллинг — до первых живых тестов;
- каталог миров — он у тебя уже есть, трогаем только формат тегов;
- аренду сервера — после того, как 10 человек поиграют.
